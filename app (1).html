How the temper is measured

It's about entropy, not tricks. Every character you add multiplies the number of possible passwords, not just adds to it. A longer password with a smaller character set often beats a shorter one stuffed with symbols — that's why length matters more than complexity.

We measure strength in bits of entropy: roughly, length × log₂(pool size). Each bit doubles the number of guesses an attacker needs to try every combination. The color scale borrows from real blacksmithing: as steel is heat-treated it passes through pale straw, gold, and bronze before reaching blue — the hardest, most durable temper. Your strongest passwords land in that same blue.

Crack times assume someone has your password's hash and is guessing offline as fast as modern hardware allows — a worst-case, not a scare tactic.

What "tempering" does

Start with words you can actually recall — that's the part your memory does. Then we heat-treat them: swap some letters for look-alike numbers and symbols (a → @, e → 3, i → 1, o → 0, s → $), and randomly recase letters. The result is much harder to guess than the plain phrase, while staying close enough to what you typed that you can still reconstruct it.

Four or five unrelated words tempered this way usually lands in "blue temper" territory — and it's far easier to remember than a random string of the same length.

        Why order isn't always obvious

        Raw entropy math can be misleading. A password like P@ssw0rd mixes letters, a symbol, and a digit — but cracking tools try common substitutions on dictionary words first, so it falls fast. Meanwhile correct horse battery staple–style passphrases look "simple" but their length alone makes them far harder to brute-force.

        The lesson: length and unpredictability beat surface-level complexity almost every time.
